# NeuroWave

NeuroWave is a browser-based binaural tone generator that creates separate tones for the left and right ears. Choose a frequency band and adjust the sound to listen to continuous binaural tones through stereo headphones.

The audio is generated in real time using the Web Audio API. Playback continues without an automatic time limit by default, with no intentional on/off pulses or automatic frequency sweeps, until you press Stop.
