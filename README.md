# NeuroWave

NeuroWave is a browser-based binaural tone generator that creates audio in real time using the Web Audio API. It plays a slightly different tone in each ear through separate stereo channels, allowing users to select a beat-frequency difference and carrier frequency.

The app includes Delta, Theta, Alpha, Beta, and Gamma frequency-band presets, adjustable volume, waveform visualizations, and Play, Pause, Resume, and Stop controls. Playback is continuous by default with no automatic time limit; the tones continue until the user stops them. The app does not intentionally add on/off pulses or automatic frequency sweeps.

NeuroWave runs directly in a modern web browser and is designed for use with stereo headphones. Its frequency labels describe commonly used EEG categories; listening to the tones does not guarantee any particular brain state or medical benefit.
